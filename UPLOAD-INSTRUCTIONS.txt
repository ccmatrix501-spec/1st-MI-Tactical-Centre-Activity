1st M.I. Tactical Centre – Discord Activity package (based on v1.4.8)

This package contains your original web build PLUS the files needed
to run it as a Discord Activity on Vercel.

FILES
-----
api/token.js                  → Vercel serverless function for Discord OAuth
public/discord-activity.js    → Client-side Discord SDK bootstrap
mi-web-update-v1.4.8/
  index-D8SEAL-n.js           → Your original app (unchanged)
  version.txt
DISCORD-ACTIVITY-SETUP.md     → Full setup guide (read this)

QUICK START
-----------
1. Read DISCORD-ACTIVITY-SETUP.md
2. Add DISCORD_CLIENT_ID and DISCORD_CLIENT_SECRET in Vercel
3. Place api/token.js and public/discord-activity.js in your project
4. Put your real Client ID inside discord-activity.js
5. Set the URL Mapping in the Discord Developer Portal
6. Deploy and test inside a Discord voice channel

The original app files are left untouched so your normal website
continues to work outside Discord.

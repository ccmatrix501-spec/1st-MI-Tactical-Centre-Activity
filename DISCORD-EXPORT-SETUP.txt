1st M.I. TACTICAL CENTRE — DISCORD CHANNEL / THREAD EXPORT
==========================================================

WHAT THIS UPDATE ADDS
- Keeps the normal .JSON download export.
- Inside the Discord Activity, Export Save now opens a destination window.
- Select any text channel the Tactical Centre bot can see.
- Select an active thread under that channel, or choose No Thread to post directly.
- The generated .JSON is uploaded to Discord as a file attachment.
- The last selected channel/thread is remembered on that device.

VERCEL ENVIRONMENT VARIABLES REQUIRED
1. DISCORD_CLIENT_ID
2. DISCORD_CLIENT_SECRET
3. DISCORD_BOT_TOKEN   <-- NEW for Discord file export

The bot token must stay in Vercel Environment Variables. Never place it in index.html,
discord-export.js, the React bundle, or any public GitHub file.

DISCORD BOT PERMISSIONS
The bot needs, for the destinations you want to use:
- View Channel
- Send Messages
- Attach Files
- Read Message History (recommended)
- Send Messages in Threads

If you use private threads, the bot must also be able to access/join them.

HOW TO DEPLOY
1. Upload this entire folder/ZIP to the same Vercel project you use for the Discord Activity.
2. Add DISCORD_BOT_TOKEN in Vercel -> Project -> Settings -> Environment Variables.
3. Redeploy.
4. Launch Tactical Centre as a Discord Activity in your server.
5. Create/fill a cert and press Export Save.
6. Choose Download .JSON OR select Discord Channel + optional Thread and press Export to Discord.

1st M.I. Tactical Centre — Web / Discord Activity Export Setup
===============================================================

THIS ZIP IS THE GITHUB / VERCEL WEB BUILD.
The desktop / Microsoft Store app keeps its existing licence-key system.
The web build does NOT require or validate a licence key.

Required Vercel Environment Variables
-------------------------------------
DISCORD_CLIENT_ID=1532302380237066271
DISCORD_CLIENT_SECRET=<your Discord application client secret>
DISCORD_BOT_TOKEN=<bot token for the same Discord application>

After adding/changing variables, redeploy the Vercel project.

Discord application / bot requirements
--------------------------------------
1. The application must be configured as a Discord Activity.
2. The bot must be installed in the server where exports will be sent.
3. Give the bot permissions for the destinations you want to use:
   - View Channel
   - Send Messages
   - Attach Files
   - Send Messages in Threads (for thread exports)
4. Users launching the Activity will be asked for Discord OAuth scopes used to verify their own server/channel access.

Export behaviour
----------------
When an existing Tactical Centre "Export Save" action creates a JSON download,
this web package opens an Export Save picker instead:

- Download .JSON to Device
- Send to Discord
  - Select Channel
  - Select active Thread (optional for text channels; required for forum channels)

The JSON payload itself is not changed.

Security
--------
- DISCORD_BOT_TOKEN stays in Vercel environment variables and is never placed in browser JavaScript.
- Discord user access tokens are kept in page memory only.
- The destination API filters channels using the authenticated user's Discord permissions.

Files added/updated
-------------------
web-compat.js                  Web-only licence bypass. Does not affect desktop builds.
discord-activity.js            Discord Activity OAuth/authentication bootstrap.
discord-export.js              Web export destination picker.
api/discord-destinations.js    Lists selectable Discord channels/active threads.
api/discord-export.js          Uploads the JSON file through the Discord bot.
api/token.js                   Exchanges Activity OAuth codes on Vercel.
index.html                     Loads the web-only compatibility/export scripts before the app bundle.
